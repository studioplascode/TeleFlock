Audit date 2026-10-21, updated for 0.4.0 on 2026-10-22 (§0), for 0.4.1 on 2026-10-23, 0.5.0 on 2026-10-26, 0.5.1, 0.5.2 and 0.5.3 on 2026-10-27, 0.6.0, 0.6.1 and 0.7.0 on 2026-10-29, 0.8.0, 0.8.1 and 0.9.0 on 2026-11-01, 0.9.1, 0.9.2 and 0.9.3 on 2026-11-03 (§0). Sources: `docs/spec.md` §2–§6, `docs/research/omp.md` §1 and §10–§12, `docs/research/herdr.md` §13.
Each row traces the path **UI entry (desktop / mobile) → frontend call → host/app method → hostd path → status**.

**Status key**
- ✅ **verified**: the code path was traced end to end and exercised. "demo" means it was run in headless Chromium on `?demo` at 1440×900 and/or 412×892. "test" means a unit test covers it. "lab" means it ran against a real omp (18.13.3 until 0.7.0, 18.14.2 for 0.8.0, 18.15.0 for 0.9.0, 18.16.0 for 0.9.1) and herdr 0.9.5 in an isolated lab (own HOME, hostd home and herdr session, a mock model provider, a fake `gh` where a PR was needed), through the real UI in headless Chromium unless it says "protocol".
- ⚠️ **implemented, unverified or partial**: the code path exists, but it was not exercised against a real host, or one platform/variant is missing.
- ❌ **missing**: there is no UI path.

**hostd path legend**: C = collab guest · B = tf-bridge extension (since 0.6.0 also the data plane: live frames + the session file) · I = herdr keystroke injection (guarded by §3.6; idle-only except commands omp runs while streaming, such as `/collab`) · H = herdr API · G = git/gh/fs exec · L = local client (tf-client / Tauri).

Every builtin is reachable from the session `/` palette, on desktop and mobile. The palette shows argument hints, and its sub-pickers are built from omp's own subcommand metadata.
