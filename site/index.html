  3. Add host → Tailscale SSH → MagicDNS name or 100.x IP, user.
Host prerequisites
  1. sudo tailscale set --ssh and a tailnet policy that lets your devices SSH here.
  2. herdr and omp ≥ 18.12 installed.
  3. TeleFlock deploys its daemon to ~/.teleflock on first connect.
Optional one-tap setup
  1. herdr omp integration (precise states)
  2. Share every omp session with TeleFlock
  3. Global bridge extension (precise controls)
